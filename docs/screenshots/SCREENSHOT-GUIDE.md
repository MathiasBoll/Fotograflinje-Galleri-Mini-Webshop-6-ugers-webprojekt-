## Sådan tager du screenshots

### Windows
- Tryk `Windows + Shift + S` for Snip & Sketch
- Vælg område og gem filen
- Eller brug Print Screen og indsæt i Paint

### macOS
- Tryk `Cmd + Shift + 4` for screenshot
- Klik og træk for at vælge område

### Browser DevTools (anbefalet)
- Åbn DevTools (F12)
- Tryk `Ctrl + Shift + P` (Windows) eller `Cmd + Shift + P` (Mac)
- Skriv "screenshot"
- Vælg "Capture full size screenshot" eller "Capture screenshot"

## Tips

- Sørg for at browseren er i en pæn størrelse (ikke fuld skærm)
- Fjern personlige oplysninger hvis nødvendigt
- Brug konsistent zoom level på alle screenshots
- Sørg for at UI elementer er synlige og læsbare
- Test at filerne kan åbnes og vises korrekt i README.md
